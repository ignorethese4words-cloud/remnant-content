# Remnant V4 Content

This repository serves the Remnant app's published V4 county packs.

The authoritative machine-readable manifest is [the V4 pack index](https://raw.githubusercontent.com/ignorethese4words-cloud/remnant-content/main/v4/pack-index.json).

Research records and media approvals are maintained in the Remnant V4 Supabase project. Legacy county packs are retired and are not served to the application.
